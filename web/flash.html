Flash lynx from your browser.

One click puts the lynx firmware on a Seeed XIAO ESP32-S3 Sense: servos, camera, and a control layer you reach over your network by HTTP or MCP.

01install~2 min

  1. Plug the XIAO into this computerwith a USB-C cable that carries data. A bare board, or the assembled lynx through its base port.
  2. Click Installand pick the port named USB JTAG/serial or ESP32-S3. Choose Erase on a first install.
  3. Join the lynx-xxxx Wi-Fi hotspotfrom your phone when flashing finishes. The setup page opens by itself: pick your network and save the device token it shows you.

This browser can't reach USB devices. Use Chrome or Edge on a desktop.

USB access needs a secure page (https).

No port in the list? Hold the board's BOOT button while plugging it in, then try again.

02what you getfirmware

  • first bootSetup hotspotlynx-xxxx with a setup page. Hold BOOT 3 s to bring it back later.
  • httpREST APIPosition, rest pose, sweep, camera settings and snapshots at lynx-xxxx.local.
  • agentsMCP serverLook, center, sweep, snapshot and stream URL at /mcp.
  • port 81Live videoMJPEG, which browsers, VLC, ffmpeg and Home Assistant all read.

03command linePlatformIO

$ git clone https://github.com/alexnodeland/lynx
$ cd lynx/firmware/lynx
$ pio run -e xiao -t upload
$ pio device monitor        # type 'info' or 'token'

Every call needs the per-device token, shown on the setup page and by the token serial command. Source and API reference: firmware/lynx.
