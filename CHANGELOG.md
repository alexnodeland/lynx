# Changelog

## 0.4.1 (2026-10-21)

- **MCP docs for agents:** fuller `instructions`, a `guide` tool and `lynx://guide` resource (the manual),
  `lynx://status`, three prompts (`look_around`, `find`, `check`), a description on every argument, and
  `readOnlyHint` / `idempotentHint` / `destructiveHint` on every tool.
- **Security:** wrong tokens are throttled per address on both ports (`429` + `Retry-After`, 1 s doubling to
  5 min). `POST /api/token/rotate`, and a Home Assistant *Rotate token* button that stores the new token itself.
  Threat model in `docs/security.md`, reporting in `SECURITY.md`. Native tests for the throttle.
- Home Assistant: brand images ship with the integration (`brand/`, HA 2026.3+), and the HACS brands check runs.
- README and site lead with agents, Home Assistant, tracking and custom models. Parts cost: ~$43 ([BOM](hardware/production/BOM.md#cost)).

## 0.4.0 (2026-10-21)

- Carrier PCB: KiCad 10 project generated by `make_carrier.py`, autorouted, ERC/DRC clean, with JLCPCB-ready fab outputs (`just pcb`).
- **On-device detection:** faces or cat faces (ESP-DL), with `near`/`far` range. It runs at ~4 fps on a scaled copy
  of each frame, so the stream keeps its 20 fps. Exposed on REST (`/api/detections`, `/api/detect`), MCP (`detect`),
  Home Assistant (occupancy and count sensors, detection switch, model and range selects), and the dashboard (live boxes).
- **Follow mode:** keeps the nearest face centred, using no-overshoot track moves. It holds, then returns to rest.
  Manual moves pause it. `lib/follow` has native tests, including a closed loop.
- `/api/detect/image` runs detection on an uploaded JPEG (`?debug=1` returns the model's input).
- **Custom models (Edge Impulse):** `just capture <label>` collects training images with lynx itself, and
  `just model-add export.zip` installs an export as `model: custom` (FOMO boxes or a classifier's label). Proven on
  the board with a public export; CI builds with it.
- **Presets and patrol:** up to 8 named positions and a patrol tour with dwell (REST, MCP, serial, and Home Assistant
  as a preset select, a patrol switch and save/delete actions). One arbiter decides who moves the head:
  manual > follow while it has a face > patrol. `lib/presets` has 8 native tests.
- **Several viewers and pushed events:** port 81 is now a small server of its own. One frame producer is shared by up
  to 4 clients (three viewers measured at ~15 fps each), and `GET :81/events` pushes the status on every change.
  Home Assistant listens to it for instant updates and keeps polling as the fallback.
- **Over-the-air updates with automatic rollback:** `POST /api/update` (image, chip, app-descriptor and SHA-256 checks),
  a dashboard firmware card, `just ota`, and a Home Assistant update entity that installs GitHub releases.
  A new image proves itself for 45 s before it's kept; a build that crashes on purpose was rolled back on the board.
  Releases now also carry `lynx-app-vX.bin` and a `lynx-vX.json` manifest.
- **microSD recording:** snapshots on detection (a burst, then one per 30 s), a timelapse, and retention past 90 %.
  Files are named by date from NTP; the API lists, downloads and deletes them (path-checked), there's an MCP
  `recordings` tool and Home Assistant entities. Off by default. Not yet verified with a card in the slot.
- MCP `snapshot` takes `annotate: true` to draw the current detections on the image.
- Fix: the demo sweep ends at the rest pose instead of lens-up.

## 0.3.0 (2026-10-20)

First public release.

- **Hardware:** eight printed parts, one screw type (9 × M2 × 8), CAD-validated pan ±90° / tilt ±60°
  (clear to ±90° tilt), magnet mount, a single USB-C cable through a panel socket.
- **Firmware:** eased pan/tilt motion with a 45° rest pose; camera snapshots and an MJPEG stream; a REST API;
  an on-device MCP server (2026-07-28 and 2025-era clients); a per-device token; a first-boot setup
  hotspot with captive portal; mDNS with IPv6. 39 native tests.
- **Home Assistant:** an integration (HACS) with zeroconf discovery, camera + live view, pan/tilt,
  camera settings, diagnostics and a `lynx.look` action. 20 tests, hassfest, HACS validation.
- **Website:** an immersive landing page, a 13-step 3D build guide, and a browser flasher.
